# LocalImageAgent — Local Image Processing MCP Server

A Windows MCP server for image processing via ImageMagick.

## Requirements

- Windows 10/11
- Python 3.12+
- [ImageMagick 7](https://imagemagick.org/script/download.php#windows) (add to PATH during install)

## Setup

```powershell
.\bootstrap.ps1
```

That's it. The script will:

1. Create a Python virtual environment (`.venv`)
2. Install all dependencies
3. Detect ImageMagick automatically
4. Write `config.json`
5. Create `run_server.ps1` launcher
6. Print your MCP client config snippet
7. Start the server

## Running manually

```powershell
.\run_server.ps1
```

## MCP Client Configuration

After running bootstrap, copy the printed JSON snippet into your client config. Example for Claude Desktop (`%APPDATA%\Claude\claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "local-image-agent": {
      "command": "C:\\path\\to\\LocalImageAgent\\.venv\\Scripts\\python.exe",
      "args": ["C:\\path\\to\\LocalImageAgent\\src\\main.py"],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `compress_image` | Compress a single image, optionally to a max KB target |
| `compress_folder` | Compress all images in a folder |
| `resize_image` | Resize with fit / fill / exact modes |
| `batch_resize` | Resize all images in a folder |
| `convert_image` | Convert between JPG, PNG, WebP, AVIF, TIFF, BMP |
| `batch_convert` | Convert all images in a folder |
| `strip_metadata` | Remove EXIF and metadata |
| `image_info` | Get format, dimensions, color space, DPI, metadata |
| `create_thumbnail` | Generate a thumbnail preserving aspect ratio |

## Supported Formats

Input: JPG, JPEG, PNG, TIFF, BMP, GIF, WebP, AVIF  
Output: JPG, PNG, TIFF, BMP, WebP, AVIF

## Configuration

`config.json` is auto-generated by bootstrap. You can manually set `magick_exe` if ImageMagick is in a non-standard location.

```json
{
  "magick_exe": "C:\\Program Files\\ImageMagick-7.1.1-Q16-HDRI\\magick.exe",
  "log_level": "INFO"
}
```
